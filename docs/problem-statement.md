
# Student Project & Thesis Management System

## Problem Statement

Managing university projects and theses manually can make
proposal tracking, supervisor feedback, deadline management,
and document organization difficult.

This project aims to develop a centralized web application
for managing student projects and theses from proposal
submission to final evaluation.

## User Roles

1. Student
2. Supervisor
3. Admin

## Main Objectives

- Manage project proposals.
- Assign supervisors.
- Track milestones and progress.
- Provide supervisor feedback.
- Manage final thesis submissions.
